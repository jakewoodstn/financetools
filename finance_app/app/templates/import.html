How import works

Imports write to raw_transactions, then promote to bank_transactions for accounts with import_transactions=1. SimpleFIN is the default for ongoing sync. CSV is for direct bank downloads — headers are auto-mapped (date, amount, description). Merge skips duplicates; Replace clears unstaged rows in the file date range first.
